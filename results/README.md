# Monte Carlo results

This directory retains the two Monte Carlo validation datasets cited by the
paper. Both experiments used 100,000,000 samples for every dimension-alpha
pair and the recorded deterministic seed for each row:

- `paper_validation_dimensions_2_3_4_5_8.csv`
- `paper_validation_dimensions_9_10_12_20.csv`

The command-line program also writes timestamped CSV files and optional
diagnostic plots here. Those routine generated files are ignored by Git.
